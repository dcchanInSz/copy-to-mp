# copy-to-mp

将 Markdown 格式的文章，以公众号格式复制。支持多彩主题预览，复制后样式完整保留。

## ✨ 功能特性

- **📝 Markdown 编辑器** - 实时预览，所见即所得
- **🎨 多彩预览主题** - 4 种精美主题，标题彩色显示
- **📋 一键复制** - 复制到公众号编辑器，样式完整保留
- **💾 本地存储** - 自动保存内容，防止丢失
- **🌙 暗色模式** - 保护眼睛，夜间写作更舒适
- **🖥️ 桌面应用** - 支持 Windows/macOS/Linux

## 🚀 快速开始

### Web 版本

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

### 桌面应用（Tauri）

#### 前置要求

- **Rust**: `winget install Rustlang.Rust.MSVC`
- **Node.js**: 18+
- **Windows**: 需要安装 WebView2（Windows 11 已内置）

#### 安装与运行

```bash
# 安装依赖
npm install

# 开发模式运行桌面应用
npm run dev:tauri

# 构建桌面安装包
npm run build:tauri
```

构建完成后，安装包位于 `src-tauri/target/release/bundle/` 目录。

## 📖 使用说明

1. 在左侧编辑器中输入 Markdown 内容
2. 选择喜欢的预览主题（默认/学术/技术/杂志）
3. 点击顶部「复制」按钮
4. 粘贴到公众号编辑器，样式完整保留

### 工具栏快捷操作

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| H1-H4 | 插入标题 | `#`, `##`, `###` |
| B | 粗体 | `**text**` |
| I | 斜体 | `*text*` |
| S | 删除线 | `~~text~~` |
| `code` | 行内代码 | `` `text` `` |
| ``` ``` | 代码块 | ```` ``` ```` |
| • | 无序列表 | `- ` |
| 1. | 有序列表 | `1. ` |
| ❝ | 引用 | `> ` |
| — | 分割线 | `---` |
| 🔗 | 链接 | `[text](url)` |
| 🖼️ | 图片 | `![alt](url)` |
| 📊 | 表格 | 插入表格模板 |

## 🛠️ 技术栈

### 前端
- **Vue 3** - 前端框架
- **TypeScript** - 类型安全
- **Vite** - 构建工具
- **marked** - Markdown 解析
- **dompurify** - HTML 安全过滤

### 桌面端（Tauri）
- **Rust** - 后端逻辑
- **Tauri 2** - 桌面框架
- **WebView2** - Windows 嵌入式浏览器
