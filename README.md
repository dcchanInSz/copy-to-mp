# copy-to-mp

将 Markdown 格式的文章，一键复制并保留样式粘贴到公众号编辑器。

## ✨ 功能特性

- 📝 **Markdown 编辑器** - 实时预览，所见即所得
- 🎨 **多彩预览主题** - 4 种精美主题，标题彩色显示
- 📋 **一键复制** - 复制后直接粘贴到公众号，样式完整保留
- 💾 **本地存储** - 自动保存内容，防止丢失
- 🌙 **暗色模式** - 保护眼睛，夜间写作更舒适

## 🎨 预览主题

| 主题     | 描述                   | 标题颜色                            |
| -------- | ---------------------- | ----------------------------------- |
| **默认** | 现代简洁，适合日常写作 | 🔴 红 → 🟢 青绿 → 🟠 珊瑚 → 🔵 深蓝 |
| **学术** | 衬线字体，正式严谨     | 🟤 棕色系                           |
| **技术** | 深色主题，代码突出     | 🔴 红 + 🟢 青 + 🟣 紫 + 🟡 金       |
| **杂志** | 优雅文艺，视觉丰富     | ✨ 金色系                           |

## 🚀 快速使用

### Web 版本

```bash
# 安装依赖
npm install

# 启动
npm run dev
```

访问 http://localhost:3000 即可使用。

### 桌面应用

```bash
# 安装依赖
npm install

# 开发模式运行
npm run dev:tauri

# 构建安装包
npm run build:tauri
```

## 📖 使用说明

1. 在左侧编辑器输入 Markdown 内容
2. 选择喜欢的预览主题
3. 点击顶部「复制」按钮
4. 粘贴到公众号编辑器

### 工具栏

| 按钮   | 功能     | 快捷键           |
| ------ | -------- | ---------------- |
| H1-H4  | 插入标题 | `#`, `##`, `###` |
| B      | 粗体     | `**text**`       |
| I      | 斜体     | `*text*`         |
| S      | 删除线   | `~~text~~`       |
| `code` | 行内代码 | `` `text` ``     |
| ` `    | 代码块   | ` ``` `          |
| •      | 无序列表 | `- `             |
| 1.     | 有序列表 | `1. `            |
| ❝      | 引用     | `> `             |
| —      | 分割线   | `---`            |
| 🔗     | 链接     | `[text](url)`    |
| 🖼️     | 图片     | `![alt](url)`    |
| 📊     | 表格     | 插入表格模板     |
